# Controls

There are two user input files, one for the X56 hotas and one for keyboard controls.  Whichever one you want to use must be named user_input.py, rename the other one something else.  If using the X56 hotas, you need to install the software from [logitech](https://support.logi.com/hc/en-gb/articles/360024844133--Downloads-X56-Space-Flight-H-O-T-A-S). Use the Windows 10 version even if on Windows 11.  The control bindings should be already saved on the controller.

Current Keyboard Controls as defined in `userinput.py`
- W: Pitch down
- A: Roll right
- S: Pitch up
- D: Roll left
- I: Increase heave
- J: Yaw right
- K: Decrease heave
- L: Yaw left
